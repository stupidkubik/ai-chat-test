## Команды и ограничения

- `npm test`: 24/24. Первая попытка в sandbox завершилась `listen EPERM` на `127.0.0.1`; повторный запуск с разрешённым loopback прошёл.
- `npm run lint`, `npm run typecheck`, `npm run build`: успешно. Build — Next.js 16.3.6, `/` статический, `/api/chat` динамический.
- `vercel inspect` подтвердил targets, `vercel env ls` — только область секрета, `vercel logs` — запросы `/api/chat` без серверных исключений; сырые пользовательские сообщения и секреты в отчёт не переносились.
- Реальное закрытие вычисления у провайдера после Stop не видно со стороны приложения. Проверено закрытие браузерного потока и возобновление работы UI; unit-тест подтверждает закрытие соединения с mock.
- На физическом телефоне и с виртуальной клавиатурой проверка не проводилась. Изолированный Chromium не может пройти защиту Vercel без авторизации.

**Вывод:** функциональные сценарии на фактическом Production работают; ссылка из запроса указывает на Preview без ключа и возвращает 500. До передачи внешнему проверяющему нужен доступный без Vercel Login адрес и отдельное решение, нужен ли работающий Preview.
