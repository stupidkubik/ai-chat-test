# Развёртывание на Vercel

Рабочий адрес приложения: [ai-chat-test-lake.vercel.app](https://ai-chat-test-lake.vercel.app/). При проверке P09 26.09.2026 страница открылась в изолированном Chromium без входа в Vercel; живой запрос получил потоковый ответ, остановка ответа работала. Подробные результаты — в [QA.md](QA.md).

Проект Vercel `ai-chat-test` использует Next.js 16.3.6, корень репозитория как Root Directory и Node.js 24.x. Маршрут `/api/chat` выполняется на сервере. `OPENROUTER_API_KEY` задаётся в переменных окружения Production; значение ключа не хранится в Git и не передаётся браузеру.

Перед отправкой ссылки работодателю стоит ещё раз открыть основной адрес в браузере без авторизации и отправить короткий вопрос: доступность внешнего сервиса и бесплатной модели может меняться. Ошибки 429, таймаут и обрыв соединения проверены локально с mock; результаты есть в [QA.md](QA.md).

`app/api/chat/route.ts` задаёт `runtime = "nodejs"` и `maxDuration = 300` (максимум Hobby с Fluid compute); `vercel.json` включает `supportsCancellation` для маршрута чата. `.gitignore` исключает `.vercel/` и `.env.local`.
